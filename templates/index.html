PDF Rendering Service

Overview

This service allows you to generate PDF files from web pages or HTML content. It uses a headless browser to render the content and convert it to PDF format.

The service is running at {{PDF_ENDPOINT}}

Configuration

The service can be configured using environment variables or command line arguments. Environment variables can be set in an .env file.

Environment Variable Command Line Flag Description Default
PDF_ENDPOINT -path PDF endpoint or path /pdf
LISTEN_ADDRESS -host Listen address localhost:3005
PROFILING_ENABLED -profiling Enable profiling false
PAGE_POOL_SIZE -pool Page pool size 5
LOG_LEVEL -log Log level (debug, info, warn, error, fatal, panic) info

Example: Start the service with custom configuration: PDF_ENDPOINT=/convert LISTEN_ADDRESS=0.0.0.0:8080 PAGE_POOL_SIZE=10 ./go-pdf ./go-pdf -path /convert -host 0.0.0.0:8080 -pool 10

Request Methods

GET Request

Use a GET request to convert an existing web page to PDF by providing its URL.

GET {{PDF_ENDPOINT}}?url=https://example.com

Optional Parameters:

  • scale - Scale of the webpage rendering (default: 1.0)
  • pageRanges - Paper ranges to print, e.g., '1-5, 8, 11-13'
  • printBackground - Whether to print background graphics (default: true)
  • landscape - Paper orientation (default: false)
  • paperWidth - Paper width in inches (default: 8.27)
  • paperHeight - Paper height in inches (default: 11.7)
  • displayHeaderFooter - Whether to display header and footer (default: false)
  • headerTemplate - HTML template for the print header
  • footerTemplate - HTML template for the print footer
  • preferCSSPageSize - Whether to prefer page size as defined by CSS (default: false)

POST Request

Use a POST request to convert custom HTML content to PDF by sending the HTML in the request body.

POST {{PDF_ENDPOINT}}
Content-Type: text/html
<html><body>Hello World</body></html>

The same optional parameters as the GET request can be included as query parameters. 

// Example using fetch API
fetch('{{PDF_ENDPOINT}}?paperWidth=8.5&paperHeight=11', {
  method: 'POST',
  headers: {
    'Content-Type': 'text/html'
  },
  body: '<html><body><h1>Hello World</h1><p>This is a PDF generated from HTML content.</p></body></html>'
})
.then(response => response.blob())
.then(blob => {
  const url = URL.createObjectURL(blob);
  window.open(url);
});
